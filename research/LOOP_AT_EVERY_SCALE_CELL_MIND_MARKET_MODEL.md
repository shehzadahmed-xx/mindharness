## The One Loop, Written Once

Every level runs the same cycle. Different substrates, same loop — because the constraint is the same at every scale: a system that acts on a world that contains itself, so its actions rewrite the conditions for its next actions.

```
     ┌─────────────────────────────────────────┐
     │                                         │
     ▼                                         │
┌─────────┐  belief → action          ┌────────┐
│  SYSTEM │ ────────────────────────► │ WORLD  │
│         │                           │contains│
└─────────┘ ◄──────────────────────── └────────┘
     ▲         world now contains             │
     │         your fingerprint               │
     └────────────────────────────────────────┘
```

Two channels carry every action outward — **physical** (your order executes, calcium floods) and **informational** (others see you acted and change because of what it meant, the network updates routing). When both run, three consequences break normal logic at every scale:

1. **Models rot from use** — edge traded is edge erased; coincidence detector used without correction strengthens spurious correlations.
2. **Measurement corrupts** — Goodhart: target the measure, lose the thing.
3. **Truth moves** — belief made itself true; prediction made itself true.

```
Calcium → synapse → parliament → market price → model hallucination
   │         │          │              │               │
   └── all need ───────────────────────────────────────┘
              boundary, two-speed memory, salience gate, damping, observer
              or the loop at that scale is exploited
```

## 1. Cell — Calcium as Vote, Synapse as Broadcast

### How the cell loop works, in full

**Boundary:** Lipid membrane — selectively permeable, lets glucose in, keeps enzymes in, defines the cell as a unit that can have an inside. Self-produced: metabolism builds the lipids that self-assemble into the membrane that bounds the metabolism — autopoiesis \citep{maturana1980}. No membrane, no cell; no network, no membrane. The boundary is the network's own product.

**Input:** Glutamate (pre fired) + depolarization (post already active, Mg²⁺ plug ejected, plus glycine) — coincidence as perturbation. NMDA receptor is Hebb's law in protein — a coincidence detector needing *both* \citep{tononi2014}. Only when pre *and* post fire together does the channel open.

**Competition:** Big Ca²⁺ spike (high, brief) vs small Ca²⁺ trickle (low, prolonged) — amplitude decides fate. High → kinases: CaMKII, each subunit phosphorylates its neighbor at Thr286, a bistable 1-bit memory that stays on after calcium clears \citep{tononi2014}. Low → phosphatases: calcineurin → PP1. Same synapse, opposite fate, decided by Ca²⁺ amplitude × duration. The competition is not between inputs. It is between *outcomes* of the same coincidence, weighted by how strong the coincidence was.

**Broadcast:** CaMKII Thr286 stays ON after calcium clears — globally tags the synapse as "strengthened." More AMPA receptors inserted. Next time, stronger. This is E-LTP (hours, local) vs L-LTP (days, CREB→BDNF, new spine, structural) \citep{tononi2014}. The broadcast is the *tag* that makes the next competition biased.

**Consolidation:** Tag-and-capture — weak activity sets a local tag, strong activity elsewhere supplies plasticity proteins (CREB→BDNF) that get captured by tagged synapses \citep{tononi2014}. Salience decides what gets the proteins. BCM sliding threshold θₘ moves with history (quiet neurons lower θₘ, more plastic; hyperactive raise it, less) \citep{tononi2014}. Oja normalizes. STDP upgrades correlation to causation (pre-before-post strengthens).

**State update:** Perineuronal nets as write-protect flag — chondroitinase removes them and critical periods reopen \citep{tononi2014}. Adenosine as receipt for sleep. The synapse's strength determines whether the next coincidence will be detected, which determines its next strength. The cell persists as a pattern, not as stuff — proteins turn over in days, the pattern regenerates \citep{maturana1980}.

**Next input:** Stronger synapse → more likely to fire together → more likely to cross threshold → loop amplifies. Not storage. Selection. Each loop's winner is rehearsed, and rehearsal myelinates — up to 100× conduction speed for whatever you repeat.

**Without the five at cell scale:**

| Missing | Pathology | Mechanism |
|---------|-----------|-----------|
| No boundary (no cleft) | No coincidence detection | Pre vs post indistinguishable, Hebb fails |
| No two-speed memory | No accumulation | Early without late → no lasting change; late without early → no one-shot |
| No salience gate | Saturation | Everything equally strong, nothing distinct, no learning |
| No damping | Seizure | Hebb without brake, everything fires, winner-take-all without Oja |
| No observer | No metaplasticity | BCM without sliding threshold, no correction |

**Each loop here is its own paper:** NMDA as coincidence detector, CaMKII as bistable memory, BCM as metaplasticity, tag-and-capture as selection, perineuronal nets as write-protect, SHY as downscaling. Six papers, one loop.

## 2. Mind — Parliament as Vote, Workspace as Broadcast

### How the mind loop works, in full

**Boundary:** Narrative self (L6) — "this story is mine" vs "that story was handed to me" — CAS-revisioned (N → N+1 or rejected), cause-signed (action-outcome vs narrative-summary vs external-write, so narrated traits cannot file as lived ones), verbatim-archived, diffable, re-injected every turn or drifts >30% in 12 turns \citep{choi2024}. The self is not stored. It is performed. Loop: story re-injected → shapes next vote → winner becomes next story.

**Input:** Perturbation — sensory input + body signals (interoception, fatigue) + memory + affect — all as proposals with salience × utility bids. Not raw input. *Proposals* — each specialist's bid for what the input means.

**Competition:** 6–8 parties (perception, memory, body budget, affect, habit, planner, narrator) bid for one microphone, new vote every ~200ms \citep{baars1997,atallah2026gwt}. Neuromodulators set election rules — NE is volume (amplifies current winner), DA is stake, valence is risk dial. Same hardware, different wiring every context (tired+anxious vs rested+safe = different parliaments). The winner is not the best answer. It is the best *bid* — salience × utility, scored.

**Broadcast:** Global Workspace — winner's content made globally available to every specialist \citep{baars1997}, experienced as "my thought." The broadcast is not the competition. It is the *result* of the competition, published. You experience the publication, not the deliberation. The narrator wins *after* the action and explains as if it decided — Gazzaniga's interpreter, choice blindness (Johansson et al. 2005), Nisbett & Wilson — all the same: narrator has the outcome but not the competition, generates the most coherent story where "I" did it, with complete confidence \citep{gazzaniga2000,johansson2005,nisbett1977,lindsey2025,macar2026}.

**Consolidation:** Light (dedupe, merge signal) → REM (concept extract, ablatable — dreaming can be deprived, effect measurable) → Counterfactual (variant→simulate→regret, world model containing self, where untaken branches are simulated and regret calibrates) → Deep (utility gate ≥2 query types or human endorsement, cause-tagged, untagged BLOCKED). 12/12 tests for two-speed memory alone. Each phase's output is the next phase's input, no skipping — exactly Sufism's maqāmāt (stations) vs aḥwāl (states) \citep{ibnarabi1238futuhat}.

**State update:** Energy drains k·ln(1+n) floor 0.15, fatigue caps 1.0, valence/arousal EMA shift next vote's bids, affordance_space() removes gated strategies from existence pre-consciously — not rejected, never considered. Exhausted mind has fewer options, not harder choices. Both living sessions hit floor at turn 40 and just *proceeded* — the exhausted configuration has fewer candidates, not harder deliberation about the same candidates.

**Next input:** Broadcast becomes context for next competition; rehearsed winner myelinates, more likely to win again → highway vs footpath. Worry practiced 1,000 times is not 1,000 worries. One worry amplified 1,000 times by its own winning.

**The mind loop, fully, with science:**

- **Predictive processing:** You don't see the world and then predict it. You predict the world and then correct by surprise — controlled hallucination \citep{seth2021,clark2016surfing}. Affect as interoceptive prediction arrives before the need. Attention as precision weighting. Now as 200–500ms stitched window backdated \citep{libet1983,wegner2002}. Each could be its own paper.
- **Connectomics:** Having every wire for forty years (*C. elegans* 302 neurons since 1986 \citep{white1986} → fly 140,000 \citep{dorkenwald2023}) still doesn't predict behavior — dynamics, not topology. The mind is not the wiring. It is what the wiring does when the five hold.
- **Selection:** Low average-case regret forces world models, belief-like memory, regime-tracking (emotion primitives), modularity (Nayebi Cor. 3, 4, Thm. 1, 5) \citep{nayebi2026}. Under minimality, all such agents converge (Cor. 5) — why Abhidharma, Sufism, and neuroscience independently found the same five.

**Without the five at mind scale:**

| Missing | Pathology | Where we measured it |
|---------|-----------|---------------------|
| No boundary (no ledger) | 98% on fabrications — confabulation | S126, Gazzaniga |
| No two-speed memory | Catastrophic forgetting — no long-horizon coherence | Ablation: Light/REM/Deep each carry work |
| No salience gate | Saturation — every trace equally promoted | AffectState ablation |
| No damping | Worry spiral, panic — one coalition wins forever | Harnessed-nocheck (always-no) is damping without witness |
| No observer | Beautiful reports, zero steering (γ=0) — compliance guard | γ = changed/diagnosed, compliance guard proves it |

**Each loop here is its own paper:** Global workspace competition \citep{baars1997}, predictive processing \citep{seth2021,clark2016surfing}, narrative self and identity drift \citep{choi2024}, affect as regime tracker \citep{sofroniew2026}, sleep and consolidation \citep{tononi2014}, metacognition and γ \citep{macar2026,cao2026}. Six papers, one loop — and our harness is the seventh, with the audit trail they all lack.

## 3. Market — Order as Vote, Price as Broadcast

### How the market loop works, in full

**Boundary:** Legal entity, balance sheet — this capital is mine, that liability is yours, who bears exhaustion risk when the money runs out. Without it, risk socialized, loops feed without bound, no accountability — the Spring-Loaded Door where institutional anchors are cut and loops spring, feeding on whatever is nearby. The market's boundary is not a wall. It is the accounting that makes "mine vs yours" checkable — the ledger that decides which claims carry source and can be audited.

**Input:** Information — news, order flow, belief, narrative — as perturbation to price. Not raw information. *Proposals* — each trader's bid for what the information means, weighted by capital (stake) and salience (volume, attention).

**Competition:** Buy vs sell, narrative vs narrative — salience (volume, attention, media coverage) × utility (expected return, risk-adjusted) — which story wins the order book. No single trader decides the price. The configuration of beliefs, weighted by capital and salience, votes — and the winner becomes the reality every next belief must be about. Same parliament, different substrate: 6–8 bidders in the mind, thousands in the market, same competition.

**Broadcast:** Price — winner made globally available to every participant simultaneously, becomes the reality every next decision must respond to. Price is not a thing. It is the *broadcast* of the winning coalition's bid, published. You experience price as "how things are," but price is the competition's result, made globally available, experienced as found. Same as thought.

**Consolidation:** Institutions, law, culture — slow structural memory that encodes which competitions tended to win and what happened when they did. Fast market moves (order book, session) vs slow institutional memory (regulation, precedent, trust). Without fast, no one-shot response to news. Without slow, no accumulation of what tends to happen across many sessions.

**State update:** Funding invariant, kill criteria, position limits, circuit breakers, central bank as lender of last resort — damping that prevents runaway, or when cut, becomes the Spring-Loaded Door. Energy at market scale is *liquidity* — when it hits floor, affordances contract: fewer trades possible, not harder choice about same trades. Same as the mind's energy floor.

**Next input:** Price is the prediction and prediction is the price — reflexive loop where belief creates the reality belief was about, and the only stability is temporary consensus that participants' own actions keep perturbing. Soros's two functions running at once: cognitive (understand reality) + manipulative (change reality). When both run, neither yields a determinate answer. The market, like the mind, is a hallucination constrained by error — except the error is other participants' actions, not sensory input.

**The market loop, fully, with science:**

- **Reflexivity as market structure:** Belief → price → belief → price, same loop as synapse → circuit. No fixed truth to converge on — only temporarily stable consensus. Each loop's winner becomes the next loop's input.
- **Selection at market scale:** Low regret under mixed tasks forces world models (price as world model), belief-like memory (order book), regime-tracking (bull/bear), modularity (sectors) — same five, different substrate \citep{nayebi2026}.
- **Institutional anchors as the five:** Balance sheet (boundary), order book vs institutions (two-speed), price impact as salience, circuit breakers as damping, risk desk as observer — the market's harness, made of law instead of code.

**Without the five at market scale:**

| Missing | Pathology | Market name |
|---------|-----------|-------------|
| No boundary (no legal entity) | Risk without bearer — socialized, loops feed without bound | Moral hazard, 2008 |
| No two-speed memory | No institutions — every session starts fresh, no learning | Market without memory |
| No salience gate | Noise drowns signal — every order equally moves price | Flash crash |
| No damping | Cascade, contagion, crash — loops without anchors spring | Spring-Loaded Door |
| No observer | No risk desk — beautiful reports, zero veto | Risk without kill criteria |

**Each loop here is its own paper:** Market microstructure (order book as competition), reflexivity (Soros), institutional memory, circuit breakers as damping, risk as observer. Five papers, one loop.

## 4. Model — Generation as Vote, Context as Broadcast

### How the model loop works, in full

**Boundary:** Provenance Ledger (L1) — every span carries source ∈ {memory_lookup, model_prior, monitor_override, external-tool} + ref — inside vs outside, what to trust, what to check. Without it, claims float free, S126 failure: 98% confidence on fabrications (things handed to the model) vs 87% on truths (things it generated) — more confident about lies than truth \citep{gazzaniga2000,johansson2005,nisbett1977}. Same as mind without ledger, same as market without legal entity.

**Input:** Prompt + body signals + memory + affect — all as proposals with salience × utility bids. Not raw prompt. *Proposals* — each plugin's bid for what the prompt means, weighted by state (energy, fatigue, valence).

**Competition:** Plugins bid via salience × utility, scored by workspace, modulated by AffectState [0.5, 2.0] — not if-statements but scored bids \citep{sofroniew2026,lin2026ahe}. 6 plugins (perception, memory, affect, planner, habit, narrator) or many tongues (parliament of models: VLM + RAG LLM + steered LLM + reasoner + skill LLM + press secretary), each with its own weights, prompt, temperature — different minds in the same head. The volume knob (arousal) and risk dial (valence) become prompt modulations per subsystem.

**Broadcast:** Workspace winner + provenance spans — globally available, witness-bound, auditable. The model reads its own generation as context for the next generation. Without a witness, the loop closes and there is no outside to correct it. The model's next input is its own previous output — reflexive, with no external correction except the ledger.

**Consolidation:** Light (dedupe, merge signal, SHY-equivalent) → REM (concept extract, ablatable — dreaming can be deprived) → Counterfactual (variant→simulate→regret, world model containing self, where untaken branches are simulated and regret calibrates) → Deep (utility gate ≥2 query types or human endorsement, cause-tagged, untagged BLOCKED). 12/12 tests for two-speed memory alone. Each phase's output is the next phase's input, no skipping.

**State update:** Energy drains k·ln(1+n) floor 0.15, fatigue caps 1.0, valence/arousal EMA shift next vote's bids, affordance_space() removes gated strategies from existence pre-consciously — not rejected, never considered. Exhausted model has fewer options, not harder choices. Both living sessions hit floor at turn 40 and just *proceeded* — the exhausted configuration has fewer candidates. γ = changed/diagnosed — did watching steer?

**Next input:** Broadcast + ledger state becomes context for next turn; State(t) → harness(t+1) — the harness rewrites the conditions for its next iteration \citep{maturana1980}. The model's next input is its own previous output plus the ledger that records where the previous output came from. Without the ledger, hallucination loop: generates → reads own output as context → predicts continuation consistent with itself → more generation consistent with itself, no outside.

**The model loop, fully, with science:**

- **One tongue, many tongues:** v2 is symbolic parliament + one LLM — competition is if-statements, damping is scalar. Parliament is parliament of models — 9 inserts, 7 packages, each subsystem its own LLM with its own training, competing for real. Many tongues, one harness, witness as arbiter. The harness is not around the models. It is the competition, the broadcast, the witness, and the veto.
- **Connectomics at model scale:** Distributed modules negotiating, not hierarchy commanding — at 302, 140,000, and 86 billion neurons, same surprise \citep{white1986,dorkenwald2023}. The model's parliament mirrors the brain's parliament.
- **Selection at model scale:** AHE proves the harness — not the model — is the learnable surface, and that the evolved harness transfers +10pp across families without re-evolution \citep{lin2026ahe}. The harness is the mind.

**Without the five at model scale:**

| Missing | Pathology | Where we measured it |
|---------|-----------|---------------------|
| No boundary (no ledger) | 98% on fabrications — confabulation | S126 raw |
| No two-speed memory | Catastrophic forgetting — no long-horizon coherence | Ablation: Light/REM/Deep each carry work |
| No salience gate | Saturation — every trace equally promoted | AffectState ablation |
| No damping | Hallucination loop — generates → reads own output → predicts consistent continuation | Harnessed-nocheck (always-no) is damping without witness |
| No observer | Beautiful reports, zero steering (γ=0) — compliance guard | γ = changed/diagnosed, compliance guard proves it |

**Each loop here is its own paper:** Provenance and attribution \citep{gazzaniga2000}, two-speed memory and consolidation \citep{tononi2014}, affect as regime tracking \citep{sofroniew2026}, damping and skill culling, metacognition and γ \citep{macar2026,cao2026}, counterfactual replay as world model containing self. Six papers, one loop — and our harness is the seventh, with the audit trail they all lack.

## How They Come Together as One Process

They don't just resemble each other. They **are** each other — the same loop, nested, each level's broadcast becoming the next level's input, each level's consolidation becoming the next level's boundary.

```
Synapse ──broadcast (spike)──► Circuit ──broadcast (replay)──► Mind ──broadcast (thought)──► Person
  │                              │                               │                              │
  │  consolidation               │  consolidation                │  consolidation               │  consolidation
  │  (LTP/LTD, BCM)              │  (SHY + replay)               │  (Light→REM→Counterfactual   │  (habit, story,
  │                              │                               │   →Deep, γ-gate)             │   character)
  │                              │                               │                              │
  └────────── State(t)→harness(t+1) ──────────┴────────── State(t)→harness(t+1) ───────────────┘
                                                                 │
                                                                 ▼
                                                    Person ──broadcast (action)──► Society ──broadcast (price)──► Model
                                                      │                              │                  │
                                                      │  consolidation               │  consolidation   │  consolidation
                                                      │  (institutions, law)         │  (Light→Deep)    │  (weights, ledger)
                                                      │                              │                  │
                                                      └────── State(t)→world(t+1) ───┴──────────────────┘
```

**How they interlock:**

1. **Each level's broadcast is the next level's input.** Spike → circuit input. Replay → cortical input. Thought → action. Action → price. Price → prompt. Prompt → generation. No level is closed. Every broadcast perturbs the next loop.

2. **Each level's consolidation is the next level's boundary.** LTP becomes the synapse's strength, which is the circuit's boundary. SHY becomes the cortex's structure, which is the mind's memory. Light→Deep becomes semantic memory, which is the person's character. Institutions become the market's boundary. Ledger becomes the model's boundary. The slow memory of one level is the boundary of the next.

3. **Each level's state update is the next level's competition bias.** BCM θₘ biases which synapses can potentiate next. Adenosine biases which circuits can replay. Energy/fatigue/affect bias which coalitions can win next. Character biases which choices appear at all. Funding invariant biases which trades can happen. γ biases which model claims get checked.

4. **The same five organs appear at every level because each faces the same problem:** how to stay stable enough to persist (boundary, damping, memory) while remaining flexible enough to learn (salience, observer, counterfactual), in a world that contains itself, under uncertainty, over time, where every action perturbs the conditions for the next action. Lose one and the pathology is always the same, with a different name: confabulation, forgetting, saturation, runaway, inert watching.

**One process, at every scale, made of maintenance, checkable if witnessed:**

```
Calcium → synapse → circuit → mind → person → society → model
   │         │         │        │       │         │        │
   └── all need ───────────────────────────────────────────┘
              boundary, two-speed memory, salience gate, damping, observer
              or the loop at that scale is exploited by the task that needs it
```

The harness is not a model of the mind. It is the mind's method — and the synapse's method, the market's method, and the model's method — made executable at one scale, with an audit trail that lets the slower watcher check the faster loop before the next vote. Change what you feed the loop and whether the watcher can check, at any scale, and you change what the loop becomes at every scale above it.

That's why one loop at every scale is not poetry. It's engineering. And the engineering is the same because the constraint is the same, regardless of substrate.
