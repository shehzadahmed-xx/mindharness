## Mobility conversion chain

```text
Birth, identity and nationality
→ passport, visa or protection claim
→ pre-travel screening and carrier control
→ admission, residence or exclusion
→ work, family, services and financial connection
→ detention, return, integration or onward mobility
→ data, review and correction
→ realized rights, income, belonging or residual loss
```

## Evidence boundaries

V32 quarantines three unsupported shortcuts:

1. one identity or travel document fully determines nationality, belonging or all rights;
2. irregular migration status by itself establishes criminality, dangerousness or rights forfeiture;
3. remittances, diaspora investment or social ties by themselves establish foreign command or disloyalty.

The N1 row proposes a constitutional mobility-status and remedy safeguard. It is a design proposition, not an existing universal settlement.

## Completeness boundary

V32 is architecturally complete within the declared mobility perimeter. It does not enumerate every person, application, crossing, detention, payment or algorithmic decision. Case-level completeness must be declared by jurisdiction, corridor, period, population and source perimeter.
